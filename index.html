پروکسی CORS و کلید API

اکثر این APIها از مرورگر مستقیم قابل دسترسی نیستند (CORS) و بعضی نیاز به کلید دارند. درخواست هر منبع از طریق آدرس پروکسی زیر بازنویسی و ارسال می‌شود. کلیدها و تنظیمات پروکسی فقط در همین مرورگر (localStorage) نگه‌داری می‌شوند و به جایی جز پروکسی/سرویس مقصد ارسال نمی‌شوند.

فعال بودن هر منبع و کلید آن (برای Google، کلید به‌صورت پارامتر key= ارسال می‌شود؛ برای بقیه به‌صورت هدر Authorization: Bearer):

روی هر سطر کلیک کنید تا مشخصات کامل و دادهٔ خام JSON باز شود. قیمت‌ها به دلار آمریکا و به ازای هر ۱ میلیون توکن نمایش داده می‌شوند (در صورت اعلام توسط provider).
